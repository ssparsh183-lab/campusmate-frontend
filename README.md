# 🎓 CampusMate Frontend
### Context-Aware Voice Campus OS (UI Layer)

CampusMate Frontend is the interactive user interface layer of the CampusMate system.  
It supports text and voice interaction and dynamically updates based on backend memory.

---

## 🚀 Live Website

Hosted on Netlify:

https://superlative-pony-6294c2.netlify.app

---

## 🏗 System Flow

User (Text or Voice)  
⬇  
Frontend (JavaScript Fetch API)  
⬇  
FastAPI Backend  
⬇  
Memory + Database  
⬇  
Voice Output (TTS Playback)

---

## 🎯 Features

✅ Text-based interaction  
✅ Voice input (Web Speech API)  
✅ Voice output (TTS playback)  
✅ Dynamic memory UI updates  
✅ Complaint tracking UI  
✅ Smart navigation  
✅ Daily briefing summary  

---

## 🧠 Dynamic UI Behavior

The frontend dynamically reflects backend state:

- Last complaint updates instantly
- Recent navigation updates
- Hostel memory loads on refresh
- Feature cards update based on context

---

## 🎤 Voice System

Voice interaction uses:

- Browser-based Speech Recognition
- Backend-powered Text-to-Speech
- Asynchronous audio synchronization for realistic AI responses
